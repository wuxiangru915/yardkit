# 做月球场景学到的事（12 条）

> 背景：用同一批工业资产（`yardkit`）做"月球基地"，不改模型，只换主题层。
> 所有数字都来自这次实测，不是猜的。

## 一、方法和流程

**1. 先锁死变量，再动手。**
A/B 两个模式共用一个场景函数、一个随机种子、一个机位、一套后处理，只有"主题层"不同。
如果连机位都调了，最后就说不清是颜色变了还是角度变了。

**2. 主题 = 五件套，不是"换个颜色"。**
`表面（shader） + 材质重映射 + 天空 + 灯光 + 少量新模型`。
少任何一件都会露馅：只换颜色像"刷错漆的码头"，只换天空像"晚上开灯的货场"。

**3. 保留一个"不换"的对照组。**
`mode=a` 一直留着，任何时候都能回答"到底是哪一步让它变月球的"。
删掉对照组，经验就变成了传说。

**4. 验收三条，缺一不可。**
① node 里实例化不报错、不 NaN；② headless 浏览器截图 0 console 错误；③ 内核文件 md5 不变。
前两条管"能不能跑"，第三条管"有没有偷偷改地基"。

**5. 并行做两个包时，先分文件所有权。**
月球包和治愈包同时开工，各自只能碰自己的目录，内核和测试归一个人。
26 分钟并行、零冲突，靠的不是运气，是开工前写清楚"谁能改哪个文件"。

## 二、技术上的硬规律

**6. 金属需要环境，真空里会全黑。**
`metalness=1` 的材质没有反射源就没有亮度。月球包必须自带一张"上黑下灰"的极简环境图
（`createMoonEnvironment`），否则太阳能板、旗杆、法兰全是一坨黑。
这不是 bug——现实里金属靠反射活着。

**7. 新旧/磨损是主题参数，不是模型属性。**
同一批集装箱：`amount 0.5` 是锈迹，`0.08` 是月尘。
所以材质的"脏度"要能被主题包统一压下去，不能写死在模型里。

**8. 一张"材质名 → 表面"的映射表，能换掉 40 个模型的皮肤。**
月球包只写了 15 条映射；治愈包写了 38 条。这是整套方案里性价比最高的东西。

**9. 现实的光比，比"调亮"重要。**
月球：太阳 4.6、补光 0.055、阴影是黑的、没有雾。
黄昏：太阳 5.2、环境 2.2、有雾。
"夜景≠把灯调暗"，"月球≠把颜色调灰"——变的是**光比和有无**，不是亮度。

**10. 天空决定尺度感。**
地球放在 520 米外、130 米高，才显得"远"；放近了立刻变成贴纸。
星星要小、要暗、要分布不均，否则像噪点。

**11. 细节的"尺寸"要对，不是"多少"要对。**
月壤坑一开始太小，看着像水泥地；放大坑和坑环之后才像月面。
**同一个噪声，尺度错了就是另一种材质。**

**12. 剪影决定题材，材质只改"新旧、冷暖、干湿"。**
这是最重要的一条：
- 月球实验成功，是因为月球基地**本来就是工业剪影**（圆筒、方盒、斜板）。
- 治愈包一般，是因为椅子、茶杯、植物是**另一类剪影**，程序化图元拼不出来。
- 换皮能改气质，改不了"这是集装箱还是舱段"。

## 三、下次开工前的检查单

- [ ] 这个题材的剪影，和现有资产是同一类吗？（是 → 换皮就够；不是 → 要建模）
- [ ] 主题包的五件套齐了吗？
- [ ] 金属有没有环境？磨损压下去了吗？
- [ ] 有没有留一个不换的对照组？
- [ ] 三条验收跑过了吗？

## 四、这次没做好的地方（留档）

- 手套没有小臂（`hands.js` 的已知缺口），用两个图元临时补的袖子。
- 太阳能板在真空里偏黑，cell 栅格基本看不见。
- 气闸下半截被原有货堆挡住；相机是固定的，没法挪。
- 5 个模型的碰撞盒是粗粒度包围（圆筒按方盒算），够避让，不够精确。
- `seed` 只影响磨损顶点色，不影响几何——"每台都不一样"还没做。
