# yardkit

Procedural, zero-texture three.js asset library. Surfaces are GLSL; models are built from primitives.
There are no theme packs: themes are assembled from four layers (see `docs/THEMES.md`).

Base: `${KIT:-/home/wxr/.project/yardkit}`

## Hard rules

1. **Bake every surface before use.** Call `bakeAverage(renderer, name)` and pass the resulting colors into `createMaterialStore({ averages })`. Otherwise distant pixels keep running the full GLSL shader.
2. **Metal needs an environment map.** Set `scene.environment = bakeEnvironment(renderer, sky.mesh)` or `metal`, `gunmetal`, and `chainlink` will render black.
3. **Colliders are local-space.** Props expose `userData.colliders` with `y=0` at the ground; `createLevel().place()` transforms and registers them automatically.

## Four-layer theme

```js
registerSurface('my_sand', glslBody, { tile: 3, bump: 2, amount: 0.3 });
const materials = createMaterialStore({ createMaterial, averages: AVG, surfaceMap: { concrete: 'my_sand' } });
const sky = createSky(sunDir, palette);
scene.add(sky.mesh);
scene.environment = bakeEnvironment(renderer, sky.mesh);
scene.fog = new THREE.FogExp2(palette.fog, 0.012);
const post = createPost(renderer, { quality: 'high' });
```

Tuning order: **light → fog → post → surfaceMap → new surface**. Do not start with a shader.

## Footguns

- `assets/glsl/*.glsl` is the source; `src/materials/glsl.js` is generated by `tools/build-glsl.mjs`. Rebuild after editing the source.
- When a material goes through GLSL, `MATERIAL_PRESETS` roughness/metalness are ignored; only `tint` is forwarded.
- `mergeGeos` keeps only position / normal / uv / color; custom attributes need a separate mesh.
- Fog color must match the horizon color, or a grey band appears at the end of the ground.
- Use one surface family per scene; mixing styles usually reads as “abandoned industrial park”.
